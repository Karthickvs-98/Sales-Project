# 🎮 Video Game Sales Analysis Project

## 📝 Overview
This project analyzes global video game sales data to discover trends in game popularity, platform performance, genre success, and regional preferences. The goal is to provide actionable insights for game developers, marketers, and analysts.

## 📊 Objectives
- Analyze best-selling video games globally and by region.
- Evaluate platform and genre performance.
- Visualize trends in the gaming market over time.
- Identify regional differences in gaming preferences.

## 📁 Dataset
- **Source**: [Kaggle - Video Game Sales with Ratings](https://www.kaggle.com/datasets/gregorut/videogame-sales-with-ratings)
- **Features**:
  - `Name`: Name of the game
  - `Platform`: Platform of the game release (e.g., PS4, Xbox One)
  - `Year`: Release year
  - `Genre`: Genre of the game
  - `Publisher`: Publisher name
  - `NA_Sales`, `EU_Sales`, `JP_Sales`, `Other_Sales`, `Global_Sales`: Sales in millions

## 🛠 Tools & Technologies
- Python (Pandas, NumPy)
- Matplotlib (Visualizations)

## 🔍 Sample Insights
- Nintendo has the most titles in the global top 10.
- Role-Playing Games (RPGs) are highly popular in Japan, unlike other regions.
- The PlayStation 2 is the top-selling platform in terms of game units sold.
